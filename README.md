ZcVersionBox
============

<img width="2049" height="704" alt="SnowShot_2026-04-29_18-05-27" src="https://github.com/user-attachments/assets/854bb786-c30f-4eb8-83b2-0359d6eb8846" />

一个基于 Qt 开发的本地文件版本管理工具。
轻量、简单、专注于文件级版本回退。

✨ Features
-----------

* 📁 本地文件/文件夹自动备份
* 🕒 基于 Git 的历史记录管理
* 👀 一键查看历史版本（只读预览）
* 🔁 一键恢复到指定历史版本
* ☁️ 支持云端仓库导入与同步（pull / push）
* 🖱️ 支持 Windows 右键菜单快速添加
* 🧩 托盘常驻运行，关闭窗口不退出

---

🚀 Quick Start
--------------

1. 启动应用后，点击「备份本地文件」或右键你需要备份的文件/文件夹点击「添加到版本控制」。
2. 文件变化后会自动备份并生成历史版本。
3. 在「查看历史备份」中可预览或恢复。
