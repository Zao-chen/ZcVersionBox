一个基于 Qt 开发的本地文件版本管理工具。
轻量、简单、专注于文件级版本回退。

✨ Features
-----------

* 📁 本地文件/文件夹自动备份
* 🕒 基于 Git 的历史记录管理
* 👀 一键查看历史版本（只读预览）
* 🔁 一键恢复到指定历史版本
* ☁️ 支持云端仓库导入与同步（pull / push）
* 🖱️ 支持 Windows 右键菜单快速添加
* 🧩 托盘常驻运行，关闭窗口不退出

---

🚀 Quick Start
--------------

1. 启动应用后，点击「添加文件」或「添加文件夹」，也可以拖入源路径；在设置中启用系统右键菜单后可通过右键添加。
2. 文件变化后会自动备份并生成历史版本。
3. 在「历史版本」中选择版本，即可预览、对比、恢复或编辑备注。


新版备份引擎
--------------

备份已改为独立后台服务：原生文件事件触发增量快照，内容直接写入 bare Git 仓库，界面不再执行扫描、复制或 Git 命令。停止修改 2 秒后合并备份，持续修改时每 30 秒尝试一次。

- 旧备份和配置保留在原 Documents 目录，新版不读取、不迁移；请重新添加备份对象并配置应用。
- 新数据位于 Qt 的 `AppLocalDataLocation/backup-engine`，可用 `--data-dir <目录>` 启动独立配置。
- 恢复前保存当前修改。云端快进拉取同时更新源文件；分叉时保留双方版本，冲突解决界面将在后续实现。
- 手动说明和 AI 说明使用 Git notes，不修改历史提交。AI 失败不影响已经完成的快照。
- 只支持新版快照仓库。监听失败明确报错，不切换到轮询。普通文件与空目录受支持，符号链接、特殊文件、ACL 和扩展属性不在首期范围内。

实现说明与测试命令见 [备份引擎文档](docs/backup-engine.md)。
