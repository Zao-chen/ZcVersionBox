# ZcVersionBox

基于 Qt 6.8.3 和 Qlementine 的本地文件版本管理工具，专注于文件和文件夹的自动备份、历史预览与恢复。

- 基于 Git 自动记录文件变化，支持文件和文件夹。
- 历史版本统一提供预览、恢复、对比和提交说明反馈。
- 支持云端仓库导入与 pull / push。
- 支持 AI 自动提交说明和独立的版本差异分析。
- Windows 右键入口、macOS Finder 服务、自启动和托盘常驻。
- 原生标题栏、可收起侧栏、前进后退、置顶与手动明暗主题。

## 使用

1. 安装 Git，启动应用后点击“备份本地文件”，选择文件或文件夹。
2. 应用运行时会自动检测变化并创建版本。
3. 从文件卡片进入“历史版本”，选中版本后查看、恢复或对比；“仪表盘”提供远程设置与维护操作。
4. 在“设置”中配置系统集成或 AI 服务商。关闭主窗口会隐藏到托盘；通过托盘菜单退出。

数据仍保存在系统“文档”目录下的 `ZcVersionBox`，可以继续使用现有备份和 AI 配置。默认浅色，主题可手动切换。

## 开发

使用 Qt 6.8.3、MSVC 2022（Windows）或 macOS arm64。Qlementine v1.4.2 源码固定纳入仓库并静态构建，配置阶段无需联网获取 UI 依赖。

构建、测试、打包及 Designer 编辑方式见 [开发指南](CONTRIBUTING.md)。架构边界见 [UI 架构](docs/ui-architecture.md)，业务回归和平台检查见 [回归验证](docs/ui-regression.md)。
