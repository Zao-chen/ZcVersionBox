# ZcVersionBox

基于 Qt 6.8.3 和 Qlementine 的本地文件版本管理工具。为电脑中选定的文件或文件夹建立独立同步副本，把副本建为普通 Git 仓库，让源位置保持原样并获得自动版本记录、历史预览与恢复能力。

- 基于 Git 自动记录文件变化，支持文件和文件夹。
- 历史版本统一提供预览、恢复、对比和提交说明反馈。
- 支持云端仓库导入与 pull / push。
- 支持 AI 自动提交说明和独立的版本差异分析。
- Windows 右键入口、macOS Finder 服务、Linux Nautilus 脚本入口和登录自启动。
- 对象 Sidebar、前进后退、置顶与中性浅深色主题；支持 X11 和 Wayland。
- 紧凑历史列表、可复制路径、响应式 Diff 和按需展开的 AI 结果。

## 使用

1. 安装 Git，启动应用后打开“添加备份”菜单，选择文件、文件夹或云端导入。
2. 应用运行时会自动检测变化并创建版本。
3. 从 Sidebar 选择对象直接进入历史版本；悬停或键盘聚焦版本行，右侧显示预览、对比和更多操作。双击或 Enter 对比，Alt+P 预览；更多菜单提供恢复和编辑说明，也可用 Shift+F10 打开菜单、F2 编辑说明。“概览”提供路径、统计和远程配置，删除/重建在对象更多菜单中。
4. 点击“设置”或按 Ctrl+,，通过专用侧栏打开常规、AI 和关于。可搜索设置项；点击“返回应用”恢复之前的备份页面。主题与置顶位于应用菜单。有系统托盘时关闭主窗口会隐藏到托盘，可通过托盘菜单退出；没有托盘时关闭窗口直接退出。

pull 改变受管理内容后，自动备份暂停。在概览选择“将拉取版本应用到源位置”或“保留源内容并创建新版本”。暂不选择时继续暂停，重启也不会用源内容覆盖刚拉取的版本。

普通备份、Git 同步和预览不写源；恢复、导入和明确应用拉取版本会写源，执行前需要确认。`build` 单独变化仍不触发备份；其他变化触发时可复制 build，是否提交由普通 Git 忽略规则决定。隐藏文件继续处理，链接和会递归包含备份存储的路径会明确拒绝。

数据仍保存在系统“文档”目录下的 `ZcVersionBox`，新条目使用 UUID 目录和独立记录。旧格式不会自动加载、迁移或删除；可通过导入选择旧 Git 仓库及新的本地目标。AI 配置保留。默认浅色，主题可手动切换。

Ubuntu 22.04/24.04 x86_64 可安装 `.deb`：`sudo apt install ./ZcVersionBox-v0.1.0-linux-amd64.deb`。启动器名称为 ZcVersionBox，命令为 `zcversionbox`。启用设置中的右键入口后，在 Nautilus 多选本地文件或文件夹，选择“右键 → 脚本 → 添加到 ZcVersionBox”。安装、升级和卸载保留用户备份、配置及用户级入口；登录自启动和脚本入口可在卸载前从设置中关闭。

Linux 会记录并恢复 Git 的可执行模式（`100644` / `100755`），单独 `chmod +x` 也能触发备份。完整 POSIX 权限、ACL、所有者和空目录不属于 Git 历史。安装、验证结果和 GNOME 桌面验收步骤见 [Linux 兼容说明](docs/linux-compatibility.md)。

## 开发

使用 Qt 6.8.3、MSVC 2022（Windows）、macOS arm64 或 Linux/GCC。Qlementine v1.4.2、QWindowKit、efsw 和 ZcAILib 0.2.0 均使用仓库内固定源码，配置阶段不下载依赖。SDK 保留 `AiProvider` 接口与 ABI 1，并支持可安装的 CMake package。

构建、测试、打包及 Designer 编辑方式见 [开发指南](CONTRIBUTING.md)。备份状态与失败边界见 [备份架构](docs/backup-architecture.md)，页面边界见 [UI 架构](docs/ui-architecture.md)，验证范围见 [回归验证](docs/ui-regression.md)。
