# 软件更新

ZcVersionBox 的软件更新由关于页应用信息右侧的“检查更新”按钮手动触发，不在启动时访问网络，也不执行静默安装。检查结果通过窗口提示展示，发现新版本时可打开 GitHub 发布页。这样可以避免后台网络请求打断备份监控，并让用户明确决定何时查看和安装。

## 检查流程

1. 通过 HTTPS 请求 `https://api.github.com/repos/Zao-chen/ZcVersionBox/releases/latest`。
2. 只接受稳定 Release，并严格校验 `vMAJOR.MINOR.PATCH` 版本号。
3. 使用数值比较主、次、补丁版本，不按字符串排序。
4. 显示当前版本、最新版本、发布说明和 GitHub 发布页。

网络请求有 12 秒超时。HTTP 错误、TLS 错误、JSON 格式错误和版本号错误都会显示为可重试的检查失败，不会改变本地文件或应用设置。

## 下载流程

当前平台安装包按发布工作流的固定命名匹配：

| 平台 | 安装包后缀 |
| --- | --- |
| Windows | `-setup.exe` |
| macOS | `.dmg` |
| Linux | `-linux-amd64.deb` |

下载先写入 `QSaveFile` 临时文件，完成且网络无错误后再原子提交到系统下载目录。如果目标文件已存在，则自动使用带序号的文件名，不覆盖用户已有安装包。下载支持进度显示和取消，失败或取消会清理临时文件。

应用不自行替换正在运行的可执行文件。下载完成后由用户打开安装包；没有匹配安装包的平台仍可打开 GitHub 发布页手动选择资源。
