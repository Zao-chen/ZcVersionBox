# 本地文件预览与编辑

对象详情页按“预览 / 历史版本 / 概览”排列。从侧边栏或全部备份列表打开对象时，默认查看预览。这里始终展示源位置的本地内容；历史版本里的“预览”仍导出独立副本并由系统打开。

## 浏览与提交信息

目录按文件夹优先显示名称、最近提交说明和提交时间。文件夹的提交信息包含其子内容变化，查询范围为当前方案 HEAD。提交说明可跳转历史版本并定位该提交。尚无路径提交时显示“暂无备份记录”；仓库查询失败不会阻止本地内容浏览。

文件内容与提交信息分开读取，未备份的本地改动不会被冒充为提交。导入后的源名称可以不同于仓库名称，查询使用原记录的 repositoryPath 映射。

面包屑和前进/后退支持目录与文件路径；返回预览保留浏览位置。普通、隐藏文件和空目录可见，`.git` 隐藏且受保护。文件的真实备份范围仍遵循原有 ignore、build 观察规则；仅创建空目录不会形成 Git 内容版本。

## 支持的内容

- UTF-8、带 BOM 的 UTF-16：文本与代码可查看、查找、编辑，提供行号及系统撤销/重做快捷键。
- Markdown：可切换源码与渲染；编辑在源码中进行，不执行 HTML，不自动加载网络资源，本地图片和链接限制在追踪范围内。
- Qt 支持的常见图片：显示静态帧，可适应窗口、按原始大小查看和缩放。
- 文本超过 2 MiB 或 20,000 行、图片超过 20 MiB 或 2,000 万像素，以及其他二进制或不可靠编码，使用系统应用打开。混合换行文本只读。

## 保存与文件管理

点击编辑进入编辑状态。保存或系统保存快捷键写回源文件，保留原编码、BOM、换行和权限；没有修改时不重写。新文件首次保存才创建。写入先准备同目录临时文件，再安装完整内容；新建拒绝覆盖同名目标。

保存成功仅表示“已保存到本地”。服务不会为此直接提交、上传或推进备份基线，已有监控负责后续自动备份。同步差异待处理或需要检查时，预览保留只读浏览。

文件管理只作用于已追踪文件夹内部，不能改名或删除追踪根目录。目录工具栏提供新建；条目菜单提供同目录重命名和永久删除。永久删除不会移入废纸篓，未备份修改无法从历史恢复。出现部分删除失败时保留剩余内容并报告，不修改源权限强行删除。

## 并发与生命周期

源操作通过 BackupService 的串行队列和存储锁执行，与备份、恢复和方案切换协调。写入绑定对象、方案代次、根路径身份和读取时的文件指纹；保存前再次检查。重命名、删除使用包含目录身份、文件内容和权限的快照，确认后内容变化会使操作失效。`.git`、链接和越界路径受保护，包括包含这些内容的祖先目录。

页面监听当前目录；外部变化发生时，未编辑内容刷新，编辑缓冲区保留。离开页面、切换路径或方案、维护备份与真正退出应用之前，未保存修改提供保存、放弃、取消。隐藏到托盘保留编辑状态。源操作进行期间不会通过导航或退出中断页面流程。

文件系统允许外部程序并发写入，检查不能提供跨进程的文件系统事务；删除中途发现变化或 I/O 失败可能留下部分已删除结果，界面会明确报告并刷新残留。没有新增记录格式、持久编辑草稿或崩溃恢复机制。

## 验收步骤

1. 打开一个备份文件夹，查看目录列、面包屑、提交说明跳转和前进/后退；修改一个本地文件，确认内容立即可见，提交信息在自动备份完成后更新。
2. 打开文本，修改后切换 tab，分别尝试取消、保存和放弃；保存后在历史版本确认监控生成的新版本。
3. 编辑期间使用外部应用修改同一文件，确认保存拒绝覆盖且保留编辑内容。
4. 新建文件并在保存前确认磁盘上尚不存在；保存后改名。删除确认打开后，外部修改目标，再确认删除应失败。重新确认可永久删除。
5. 查看 Markdown、图片与超限文件；检查明暗主题和 760×520 窄窗口。文件夹内的 Git 元数据不得因改名或删除操作受到影响。

自动验证只使用隔离的 zc_tests、zc_backup_tests；不得用正常应用或真实备份运行回归。预览用例前缀为 sourcePreview，可按测试函数直接选择，构建复用现有 build 目录。
