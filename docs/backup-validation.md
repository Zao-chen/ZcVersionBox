# 备份重构验证记录

日期：2026-09-24。环境：macOS 26.6 / arm64、Qt 6.6.3、Debug 构建。

## 自动验证

- 完整桌面应用构建通过；关闭 `ZCVERSIONBOX_BUILD_APP` 后核心与测试独立构建通过，无需界面第三方库。
- `ctest --test-dir build/backup-app --output-on-failure`：2/2 测试套件通过，耗时 32.56 秒。Qt Test 合计 45 个通过项（核心 41、进程通信 4）。
- 覆盖原始字节、CRLF、二进制、隐藏/忽略文件、空目录、特殊名称、增量更新、路径类型变化、不支持的文件类型，以及旧格式拒绝。
- 覆盖原生事件、启动期间事件、事件丢失、相同时间戳修改、监听失败、空闲无扫描、退避重试、任务响应性及重叠源路径串行。
- 覆盖快进拉取、历史/备注分叉、远端 lease 失效、保护未备份内容、损坏备注拒绝和只读预览清理。
- 事务测试覆盖写入、发布、源替换、Git 元数据保留、重建、并发源修改和清理失败；其中两项使用独立子进程在替换前后直接退出，验证重启回滚/收尾。
- `git diff --check` 与新核心、应用协调层、测试、主页的 clang-format 检查通过。旧备份组件、helper、轮询器及 Qt 5 入口引用搜索为空。

## 性能样本

本机临时目录中的 10,000 个小文件首次快照为 739 ms；修改一个文件后的增量快照为 317 ms，只读取该文件，写入 7 字节内容。该样本用于验证增量行为，不代表其他磁盘或大型项目的固定耗时。

## 人工验证

使用独立临时 profile 和自行创建的源文件验证了自动备份、历史对比、Finder 打开预览目录、手动 Git notes 备注、恢复、关闭主窗口后后台常驻及第二次启动唤回同一实例。恢复后的文本、隐藏二进制文件和空目录已通过文件内容检查。测试实例已正常退出。

Windows 构建、Windows/macOS 系统右键菜单安装及 Windows 人工操作尚未实机验收；已配置 `backup-checks.yml` 在 Windows 和 macOS 构建并运行测试。真实云端鉴权与 AI 服务调用尚未使用个人账户测试；同步测试使用本地 bare 远端。
